# Reports

Thư mục này chứa các bản báo cáo định kỳ của dự án **Phân tích cảm xúc review ẩm thực**. Chỉ thêm PDF đã hoàn thiện; không tạo hoặc commit file PDF rỗng.

| File dự kiến | Trọng số | Nội dung chính |
|---|---:|---|
| `Report_1_Proposal.pdf` | 10% | Bài toán sentiment analysis, câu hỏi nghiên cứu, H0/H1, phạm vi dữ liệu và sơ đồ kiến trúc Docker |
| `Report_2_DataEngineering.pdf` | 20% | MinIO, crawler ShopeeFood/Foody, luồng Raw -> PostgreSQL và SQL kiểm tra dữ liệu |
| `Report_3_EDA.pdf` | 10% | Làm sạch văn bản tiếng Việt, Data Dictionary và EDA bằng RStudio |
| `Report_4_Modeling.pdf` | 20% | Hai mô hình ML, validation, metric, so sánh kết quả và kết luận giả thuyết |
| `Report_5_FinalProject.pdf` | 20% | Docker Compose, demo end-to-end, kết quả nghiên cứu và nội dung bảo vệ |

Mỗi báo cáo cần nhất quán với phiên bản code, dữ liệu và cấu hình tại commit/tag được dùng để nộp. Tài liệu nguồn của báo cáo (nếu có) nên được quản lý cùng repository và không chứa dữ liệu cá nhân hoặc secrets.
